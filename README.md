# 📊 Retail Analytics & AI-Powered Sales Forecasting System

A professional data analytics platform that visualizes retail sales data, generates AI-powered insights, and produces automated reports through an interactive dashboard built using Python and Streamlit.

---

## 📌 Project Overview

This project is designed to help retail businesses and analysts:
- Monitor sales performance  
- Identify trends and patterns  
- Generate predictive insights  
- Automate professional report creation  

It demonstrates real-world skills in **data analytics, backend development, dashboard building, and system design**.

---

## 🚀 Key Features

- 🔐 JWT Authentication (Admin & User roles)
- 📈 Interactive Dashboard using Streamlit
- 📊 Data Visualization (Charts & Graphs)
- 🤖 AI-Based Insights Generation
- 📄 Automated PDF Report Generation
- 📂 CSV Dataset Upload & Analysis
- 🧠 Sales Forecasting Logic
- 🗂️ Modular Project Architecture
- 🧼 Clean and Maintainable Codebase
